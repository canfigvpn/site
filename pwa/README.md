# EF3 PWA — ساختار کم‌فایل

فایل‌های اصلی این پیاده‌سازی:

- `pwa.js`: ساخت دکمه نصب، راهنمای نصب، افزودن متادیتای صفحه و ثبت Service Worker
- `sw.js`: کش فایل‌های پایه و ساخت صفحه آفلاین هنگام قطع اینترنت
- `manifest.webmanifest`: نام، رنگ‌ها و تنظیمات نصب
- `pwa/icon.svg`: آیکون اپ

## اتصال به سایت

این فایل‌ها باید روی **همان origin** سایت و از مسیرهای زیر سرو شوند:

- `/pwa.js`
- `/sw.js`
- `/manifest.webmanifest`
- `/pwa/icon.svg`

در قالب سایت، قبل از بسته‌شدن `</body>` این کد را اضافه کن:

```html
<script src="/pwa.js" defer></script>
```

اسکریپت خودش دکمه «نصب اپ» را ایجاد می‌کند. برای استفاده از دکمه‌ای که از قبل در قالب وجود دارد، به آن ویژگی `data-ef3-install` بده.

## محدودیت مهم

قرار دادن این فایل‌ها فقط در GitHub باعث فعال‌شدن PWA روی `floch3.blogix.ir` نمی‌شود؛ فایل‌ها باید از همان دامنه‌ای ارائه شوند که سایت در آن باز می‌شود. PWA به HTTPS نیاز دارد. صفحه آفلاین به‌صورت درون‌خطی در `sw.js` ساخته می‌شود، بنابراین فایل جداگانه `offline.html` لازم نیست.
